# 📊 Power BI Dashboard Project

## 📌 Overview
This project presents an interactive **data visualization dashboard built using Microsoft Power BI**. The dashboard transforms raw data into meaningful insights using charts, KPIs, and filters that help users analyze trends, patterns, and performance metrics.

The objective of this project is to demonstrate **data analysis and business intelligence skills using Power BI**.

---

## 🎯 Project Objectives
- Transform raw data into meaningful insights
- Analyze trends and patterns in the dataset
- Build an interactive and user-friendly dashboard
- Demonstrate Power BI data modeling and visualization skills

---

## 🛠 Tools & Technologies
- Microsoft Power BI Desktop
- Power Query
- Data Modeling
- DAX (Data Analysis Expressions)

---

## 📂 Project Structure

| File | Description |
|-----|-------------|
| Lucky_Yadav_powerbi.pbix | Main Power BI dashboard file containing visuals, data model, and reports |

---

## 📊 Dashboard Features
The dashboard includes the following features:

- Interactive charts and visualizations
- Bar charts and column charts
- KPI indicators
- Trend analysis
- Filters and slicers for dynamic exploration
- Summary insights

These visuals allow users to quickly understand the dataset and extract meaningful insights.

---

## 🔍 Key Insights
The dashboard helps in identifying:

- Trends across different categories
- Performance comparisons
- High and low performing segments
- Overall data distribution patterns

---

## ▶️ How to Use

1. Download the `.pbix` file
2. Open **Microsoft Power BI Desktop**
3. Click **File → Open**
4. Select `Lucky_Yadav_powerbi.pbix`
5. Explore the dashboard using filters and visuals
